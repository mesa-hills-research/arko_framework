# Design guides

These guides collect ideas, not rules. A simpler approach is usually better than an elaborate one: start with the simplest agent or workflow that could meet the goal, and add agents, stages, or controls only when it falls short. Aim for autonomous runs.

- [Agent design](agent-design.md): agent roles, tools, prompting, model selection, and coordination.
- [Workflow design](workflow-design.md): workflow topology, shared state, verification, persistence, and lifecycle design.
