# Guide

This guide explains how to install and use the tool. It is long enough to be split
into several chunks when the chunk size is small.

## Install

Pick the section for your system.

### Linux

```sh
# not a heading: a shell comment in a fenced block
sudo apt install the-tool
```

### macOS

Use Homebrew: `brew install the-tool`.

## Use

Run `the-tool --help` to list the commands.

Configuration
-------------

The configuration file lives in `~/.config/the-tool/config.toml`.
